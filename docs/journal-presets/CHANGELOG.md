# New feature: journal formatting presets

- Add Edit > Journal Presets through the shared command registry and native dialog host, with a browser-preview fallback.
- Search journal, publisher and ISSN; choose artwork category and selected-object or whole-document scope.
- Preview proposed settings and source links; support Apply, Cancel, Reset and user-defined Custom settings.
- Apply native molecule/plain-text styles as one undoable change. Resizing is explicit. Preserve chemical graphs and editable objects.
- Save versioned rules and resolved settings with the native document for offline reopening.
- Add advisory export checks for physical dimensions, format, DPI and scaled type/line sizes.
- Include five starter profiles and fifteen optional, locally loaded profiles. All twenty disclose partial coverage.
- Omit journals whose numerical instructions could not be verified. Do not certify universal journal compliance.
