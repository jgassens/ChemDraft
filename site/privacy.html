Privacy

Desktop privacy and network connections

ChemDraft stores drawings locally. The inspected application code does not upload drawings for ordinary drawing, local chemistry analysis, local recognition or local naming. It does make the network connections described below. This draft is based on a source review dated 2 November 2026; it is not a runtime traffic verification.

Automatic app update checks. The stable packaged Windows app checks GitHub’s raw content service for jgassens/ChemDraft/main/latest.json after startup when no successful check is recorded within 24 hours; a failed check can retry on a later launch. Packaged macOS builds use Sparkle with automatic checks enabled and a configured 24-hour interval, fetching jgassens/ChemDraft/main/appcast.xml from the same service. Both platforms also offer a manual check. Update notices may fetch release notes from GitHub’s raw content service. Update downloads use GitHub release URLs and its download infrastructure; installation requires user approval.

Official plugin checks and downloads. With official plugins installed, automatic checks are enabled by default after startup and daily while running; you can disable them in Settings. Checks request latest-release metadata from api.github.com for the ChemDraft NMR, OPSIN, MolScribe and Orthonym plugin repositories under jgassens. Installed versions are compared locally. Installing or updating a plugin requests its checksum and ZIP from GitHub and release-assets.githubusercontent.com after user action. A failed plugin network request can automatically trigger a connection-diagnosis HEAD request to the root of one of these three hosts, including after an automatic check.

Optional engine downloads. Installing a local recognition or naming engine requires an explicit Install action, including approval of a plugin installation that needs its engine. Downloads include uv from GitHub, Python distributions and Python packages resolved by uv, MolScribe source from GitHub and model weights from Hugging Face, or the naming engine’s Centres dependency from GitHub. These downloads send package, version and platform requests, not drawings or recognition images. Exact Python-package destinations and download redirect hosts are not fully determined by this source review. The host passes recognition images and naming structures to local processes.

Optional assistant tools. The host supports user-approved installation of Claude Code from downloads.claude.ai or Codex from GitHub and its release-asset service. Sign-in uses your account with the selected provider. After consent for a plugin and tool, assistant requests can send prompts, conversation and open-page or document content, including unpublished structures, to Anthropic or OpenAI. The assistant may search the web and read external pages during a request without separate approval for each website. Its local tool connection uses a session-protected loopback server; results can become part of the provider conversation. Stored consent is reused and can be revoked. Exact vendor endpoints, authentication traffic, background behavior and retention are not established here; vendor status commands may also have network behavior that this review could not determine.

Bug and crash reports. ChemDraft opens an email draft addressed to jgassens@gmail.com for you to review, edit and send through your own email program. It can include app version, build, platform, browser engine and error details, plus anything you attach. Crash notes are stored locally until you choose to report them. No separate analytics or automatic crash-upload client was found in the inspected application source.

What services can observe. Servers and configured proxies can receive your IP address, requested URL, request timing and HTTP/TLS metadata. Download paths can identify the requested version and platform. ChemDraft’s update and download flows do not supply document content. Exact updater headers and any Sparkle system/version metadata or profiling behavior have not been established by this review. The host requests that optional CLI tools disable telemetry, error reporting and automatic updating; this does not verify every vendor’s behavior.

Review limits. Official plugin release packages live in separate repositories and were not independently audited here. Their workers are restricted to the app’s local origin, and the desktop does not provide a generic plugin network-fetch capability. Third-party package internals, updater libraries, OS network services and service-side logging or retention have not been exhaustively verified. This policy must not be read as a guarantee that no information ever leaves the computer.

This website. Visiting this page contacts the site host and Adobe’s font services at use.typekit.net and p.typekit.net for the site typography.
