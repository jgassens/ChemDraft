# ChemDraft roadmap

ChemDraft is free, open source, and runs on macOS and Windows. A [Linux beta](https://github.com/jgassens/ChemDraft/releases/tag/v1.2.0-linux-beta.2) is available. This page shows what is coming next. Dates are targets, not promises. Ideas and votes are welcome in [GitHub Issues](https://github.com/jgassens/ChemDraft/issues).

## 1.3
- Several document windows at once.
- The main toolbar in groups that fold into a single icon each when the window is narrow; plugins choose which group their buttons join.
- Floating toolbars resize along their length, with an overflow button for buttons that don't fit.
- Your own keyboard shortcuts for the keys you press over the drawing.
- Short typed shortcuts for common groups (for example c1 methyl, ph phenyl, cn nitrile), shared with Avogadro.
- Industry-standard keyboard shortcuts as the default.
- A Windows installer that installs for all users (Program Files, all-users Start Menu, silent install).
- Preferences in the File menu on macOS, and right-click a toolbar to customize it.

## Linux
Linux is in beta now (.deb and AppImage). Each Linux build is named after its parent version plus β; the Linux build of 1.2.3 is ChemDraft 1.2.3β. It leaves beta once it passes testing on real desktops (GNOME, KDE and Cinnamon, on X11 and Wayland) and has its own update system.

## Later in 1.x
- A biology clip-art plugin (antibodies, proteins, membranes).
- Avogadro integration.
- A Windows offline installer.
- Windows code signing, as soon as the signing service approves the project.

## 2.0 — early 2027
- A design refresh across the whole app.
- Docked toolbars in a ribbon at the top of the window, as an option to floating toolbars.
- Edit ChemDraft structures directly inside Word and PowerPoint.
- Launches together with the full in-app AI assistant plugin, and works with it from day one.
